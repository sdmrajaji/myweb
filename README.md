## 🛠️ Technology Stack

- **Core:** Semantic HTML5, Vanilla JavaScript (ES6+)
- **Styling:** Custom Vanilla CSS3 with Design Tokens, Glassmorphism, and Fluid Media Queries
- **Graphics & Animation:** HTML5 Canvas API (No heavy external 3D libraries)
- **Typography:** Plus Jakarta Sans, Space Grotesk, JetBrains Mono via Google Fonts
- **Icons:** Crisp Inline SVG vectors
